# 🚦 Traffic Light Sequence using Arduino Uno

## 🛠️ Components Used
- Arduino Uno
- Red LED
- Yellow LED
- Green LED
- Resistors
- Breadboard
- Jumper Wires

## 🔌 Pin Connections

| LED | Arduino Pin |
|---|---|
| Red LED | 5 |
| Yellow LED | 6 |
| Green LED | 7 |

## ⚙️ Working Sequence
1. Red LED turns ON for 3 seconds.
2. Yellow LED turns ON for 1 second.
3. Green LED turns ON for 3 seconds.
4. The sequence repeats continuously.

## 💻 Programming Language
- Arduino (C/C++-based)

## 📚 Concepts Used
- `pinMode()`
- `digitalWrite()`
- `delay()`
- Digital output control
- LED interfacing
